# data/ — instantánea que llega desde Aurex

Aquí caen los JSON que **Aurex genera y empuja** (el sitio nunca los pide ni consulta nada).
Ver `AGENTS.md` → «Sincronización en un solo sentido». Lo que haya en esta carpeta es **público**:
cualquiera puede descargarlo, así que solo debe contener lo que se quiere publicar.

Todo archivo lleva `schema_version` y `generado_en` en la raíz.
